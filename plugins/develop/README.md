# Develop

Eight portable skills for development, review and maintenance. [Install in Codex](INSTALL.md), then invoke `$develop:develop` with your outcome, or call a skill directly.

The bundled [Codex context hook](hooks/hooks.json) blocks oversized tool text with a default 20,000-byte budget per tool input or result and guides focused searches and bounded reads. It requires reviewed, trusted hooks with local orchestration and execution; see [behavior, limits and activation](docs/context-guard.md).
