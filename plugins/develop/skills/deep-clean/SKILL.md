# Deep Clean

Resolve host, roots, exclusions and authority. Apply [protections](../clean/references/protections.md) before scanning. Run the [inventory helper](references/inventory.md) once per nonoverlapping local root, writing metadata to a private report. Include hidden entries, inaccessible nodes and skipped mounts. No elevation or cloud hydration.

Distinguish logical and allocated bytes, shared storage and evidence of disposability. An audit ends with **No cleanup actions performed**. For explicitly authorized cleanup use [platform operations](../clean/references/platforms.md), revalidate each exact candidate and move eligible files to verified system Trash. If unavailable, retain and ask before deleting. Report verified outcomes and filesystem free-space changes separately.
