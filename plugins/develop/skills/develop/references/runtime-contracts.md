# Runtime identities and contracts

For changed runtimes, tools or deployments, distinguish source pins, installed packages, executed binaries, built artifacts and deployed identities. Verify the layer claimed; a source pin or image tag alone does not prove what runs. Prefer safe metadata over executing unknown launchers.

## Inspect consumed contracts

Trace changed interfaces through actual consumers, including configuration, invocation, data and error formats, partial results, cancellation, retries and cleanup. Exercise failure and interrupted paths when relevant. Report unknown identities and unavailable checks.
