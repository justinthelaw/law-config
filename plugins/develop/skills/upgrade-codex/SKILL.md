# Upgrade Codex

Default to a read-only audit of the selected clients and roots. Pin the consuming revision and use [coverage](references/coverage.md) for discovery, precedence, schemas and verification. Record exclusions, unknowns and evidence of actual loading. Never start hooks or servers merely to inspect configuration.

Classify findings as required, deprecated, optional or unverified with path, impact and evidence. For authorized repairs, change maintained source, regenerate derived metadata and test each affected client. Preserve intentional pins and disabled settings. Report coverage, changes and outstanding checks.
