# Session evidence

## Causal episodes

- Read preceding context through the initiating request, then relevant actions, results, corrections and outcome in chronological order. Match native call/result IDs. Missing context limits attribution; completion claims, silent tools and finished turns do not prove success.
- Attribute behavior to a skill only when observed invocation governed the action. Catalog entries, quotations, copied output and proposed commands are insufficient. Consider external failures and explicit steering before changing instructions.
- Identify episodes by source/session and event range. Count forked/copied/compressed/summarized events once; distinguish new actions from inherited context. Unsupported/reverted/linked histories are gaps; never guess or follow out-of-scope pointers.

## Retrieval and claims

Apply the budget across selected sources, including malformed, duplicate and rejected reads. Samples stop once complete evidence suffices; "every session" requires every accessible page in selected sources. Count distinct sessions separately from deduplicated episodes. Record unfinished pages, inaccessible sources and a private resume point at limits. Retain minimal private evidence; reviewers receive sanitized causal summaries/permitted locators.

Report selected/readable sources, relevant episodes, observed outcomes, omissions, limits, sampling/order bias and inaccessible/in-progress episodes. Partial coverage cannot prove absence across the selection; one defect can justify a narrow correction without proving recurrence.

## Testable recommendation

Use evidence/confidence + source locator/independent count → current owner → smallest useful change/expected effect → realistic scenario/observable outcome/scope boundary.

Distinguish missing guidance, stale version, conflict and execution error. Verify sources/capability gaps for skill/plugin suggestions; proposed skills are unimplemented. Hooks/rules need trigger, scope, failure behavior and permissions. Exercise a scenario capable of exposing the original failure, not text matching. Insufficient evidence is a valid result.
