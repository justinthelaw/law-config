## Rechecked deferrals and constraints

- **texthooks migration resolved:** the earlier audit deferred this pending Python 3.14 validation. The latest stable tag is 0.7.1; its Python >=3.8 requirement accepts 3.14. The missing Python 3.14 classifier and [Unreleased support note](https://github.com/sirosen/texthooks/blob/main/README.md#changelog) are not a demonstrated incompatibility. The released hook matched the legacy implementation's exact output bytes and exit codes on Python 3.14.7 across five fixtures, each run twice for idempotency: ASCII, Markdown, curly/fullwidth and ignored quotation characters, CRLF without a final newline, and custom codepoint arguments. Three additional independent fixtures also matched. Both repository hook stages passed with the selected provider.
- **znap floating branch:** no update is needed because the existing immutable pin equals upstream HEAD. Retain the immutable reference; switching to a floating branch would not advance the dependency.
- **Dependabot regression prevented:** its weekly pre-commit updates previously reverted `v0.11.0.1-1` to the older unsuffixed tag in [PR #25](https://github.com/justinthelaw/law-config/pull/25). The pre-commit update group now ignores only normalized version `0.11.0.1` for this repository URL, preserving the Zsh exclusion while allowing future versions. Dependabot's [pre-commit parser](https://github.com/dependabot/dependabot-core/blob/main/pre_commit/lib/dependabot/pre_commit/file_parser.rb) names dependencies by their full repository URL; its [Git version filter](https://github.com/dependabot/dependabot-core/blob/main/common/lib/dependabot/git_commit_checker.rb) applies exact version requirements to parsed tag versions.
- **Transitives:** this repository has no application manifest or lockfile. Hook dependencies are resolved through pre-commit's native environments; markdownlint-cli2's pinned dependencies and actionlint's Go module graph are owned by their selected upstream revisions. Do not override their leaves independently. The native environments were installed and both configured stages were run with Python 3.14.7 and npm 12.1.0.
