## Provenance and release channel

The exact npm patch is intentional: registry `next-12` is 12.2.1 while `latest`
remains 12.2.0. A published non-prerelease security patch is selected explicitly;
this does not claim that the setup guides' `npm@latest` policy installs it.

The npm release tag resolves to `ae98c62586b6fea44114f72e249e246a2981de70`;
registry `gitHead` is `136fc5dacc1a2f3d9a051dbf03a4951228144658`. These distinct
provenance fields are preserved. The registry tarball's SHA512 integrity was
verified, and every regular archive file was compared with the installed bundle.
Registry signatures were recorded but not cryptographically verified.

pre-commit v4.7.0 resolves to `65bb884a567e8be6adc51e8bfbcf26f708eb35a2`.
texthooks 1.0.0's annotated tag resolves to
`18040afd19e75f525c1d42bc64a5805982f1c9d0`. Source pins identify upstream source;
installed package metadata and executable probes establish the local test tools.

## Validation and delivery boundaries

Local validation uses executed Python 3.15.0, Node 24.22.0, npm 12.2.1 and
pre-commit 4.7.0 in task-owned environments and caches. The existing Python
3.15.0 installation supplies the interpreter without modification; the available
uv download catalog lacks that release. The official Node archive's SHA256 was
verified. Actionlint was built locally with Go 1.27.2 from its unchanged hook
source; build metadata was retained. No new Go vulnerability scan or deployed
artifact verification is claimed. No shared tool environment was upgraded.

Smartquote fixtures cover Unicode quotes, apostrophes, ASCII, non-ASCII text,
normalization exit status, repeat-run idempotence and non-mutating check mode.
Both texthooks versions normalize identically. A cold Node-hook fixture with
absolute `GIT_DIR` and `GIT_INDEX_FILE` reproduces caller-index replacement on
pre-commit 4.6.2; 4.7.0 executes the hook while preserving the index byte-for-byte
and retaining its staged file list.

At the initial assessment snapshot, all ten required local checks passed: both hook stages, Zsh syntax, six root
tests, package validation, 221 package tests, 159 bundled Iterate tests, 22
deep-clean tests and both diff checks. Bash syntax and both stages on this new
audit also passed. The package suite has one existing skip on Python 3.15 for
removed legacy unittest aliases; that case passed separately on Python 3.10.22.
Later feature integration can change the package test count. Exact-head CI,
local reruns and requested reviews are recorded in the upgrade PR; Linux-local evidence alone does not establish macOS or Windows execution.
Source changes and local installed/executed tools are distinct from built or
deployed deliverables. No Develop package installation, production deployment,
browser/native client installation or service change is claimed.

The complete open-PR inventory contained only feature-stack PRs, with no open
dependency PR to consolidate or close. Preserve those feature PRs and the
historical setup-node #31 attribution. Publication and final-stack integration
remain separate from this local validation record.
