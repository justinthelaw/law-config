[Current hook source](https://github.com/sirosen/fix-smartquotes/tree/0.2.0), [texthooks package](https://pypi.org/project/texthooks/).
- **uv and Go:** keep setup-guide installation commands unpinned so they continue to use each platform's current release, as described above.
