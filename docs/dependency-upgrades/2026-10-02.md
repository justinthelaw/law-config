## npm bundled security RCA

The official npm bulk advisory endpoint returned ten advisories affecting three installed npm bundled copies: `brace-expansion` 5.0.9 (fixed 5.0.12), `ip-address` 10.5.0 (fixed 10.7.1 or newer; current 10.7.3), and `undici` 6.28.0 (fixed 6.28.1 or newer; current compatible line 6.29.0). These versions are unchanged from npm 12.1.0 to 12.2.0. The advisory audit is **not clean**. The markdownlint installed graph has no reported advisories.

The published [npm 12.2.0 lockfile](https://github.com/npm/cli/blob/v12.2.0/package-lock.json) marks all three copies `inBundle`. Their declared parent ranges accept fixed releases, but normal downstream updates cannot replace `bundleDependencies`. The current [upstream packaging issue](https://github.com/npm/cli/issues/10062) documents failed `npm audit fix` and root-override remedies. Its [downstream reproduction](https://github.com/npm/cli/issues/10062#issuecomment-5957432933) also verifies that published npm 11.21.0 has the same affected copies, ruling out that downgrade as a remedy. The [12.2.1 release PR](https://github.com/npm/cli/pull/10060) remains open/unreleased and does not refresh them. Keep the latest stable npm parent; retry when npm publishes a refreshed bundle containing the fixed leaves. Hand-swapping vendor directories would create an unsupported CLI fork.

A disposable native `npm install --package-lock-only --ignore-scripts` audit setup stopped with `EALLOWREMOTE` before producing a lockfile; this is recorded as an audit setup limitation, not dependency incompatibility. The read-only official advisory API checked exact installed names/versions without changing any fetch/security policy.

Other newer transitive targets remain owned by their current upstream wrapper/package graph. The ledger records each installed leaf, official latest registry release and parent constraints; no blanket currentness claim or independent leaf override is made.
