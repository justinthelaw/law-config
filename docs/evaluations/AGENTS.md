# Maintain the evaluations

## Choose the right evidence

- Start with `catalog.json`. Each protocol has its own inputs, scoring rules and denominator.
- Use the PR panel for native proposals. Keep the historical ledger, source-packet study and six-repository results separate.
- Use the Honed Justin Law Writing Style guide for documentation. Lead with the result or the first action. Keep related ideas together.

## Keep the package separate

- Put benchmark environments, fixtures, scoring and portable results under `docs/evaluations/`.
- The marketplace installs `plugins/develop/`. Keep evaluator assets and links to private run state outside that package.
- Put raw profiles, logs, caches and workspaces under the repository's ignored task directory.
- Before publishing a bundle, verify hashes and check for credentials and private host paths.

## Run a fair comparison

- Before releasing either arm, freeze the task, revisions, split, prompts, workers, dependencies, resources, treatment, model, price policy and grader.
- Require a behavioral failure on the base and a passing positive control. Keep specification failures measurable on the merged code.
- Preserve every release, including empty submissions, timeouts, provider stops and incomplete metering.
- Give each changed treatment, protocol or recovery cohort a new name. Preserve published bundles and record corrections separately.
- Verify executable gates before interpreting judge scores. Separate diff quality, PR prose, position reversals, proposal spend and assessor spend.
- Leave unknown human labor and cost empty.

## Improve Develop

- Choose one measured failure or expense from the tuning split. Name the case, proposed change, expected effect and rejection criteria.
- Compare only matched cases with compatible controls. Report excluded cases and missing measurements.
- Use exposed confirmation cases for regression checks. Use fresh cases for a promotion claim.
- Test changed commands or graders with a model-free negative and positive control. Check reported aggregates against the frozen evidence.
- Use the existing authority for paid trials, publication and cleanup. Request any additional authority before the dependent action.
